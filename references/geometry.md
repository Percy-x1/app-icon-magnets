# 素材与 Fusion 的实现细节

## 图形版本与来源

优先用户上传的 SVG，其次当前应用自己的 SVG/图标资源、官方品牌包或当前官网，最后是与当前版本比对过的矢量库。记录第三方来源，不能把 LobeHub/Iconfont 说成官方发布。网页页眉可能放旧标志，而应用 favicon 是新版；两者都“来自官网”也不能证明是同一款。用户指定参考图时，图形版本和配色优先于自动选最新版。

曾验证的区别，仅作版本核对提醒，不固定为以后默认：千问与千问办公不同；千问办公三段绿标和章鱼是不同版本；Grok 与 Grok Bot 不同；智谱清言应用标志和 Zhipu 公司标志不同。不要把公司字标整串缩成 APP 图标，也不要从长字标任意重组字母。

SVG 要检查 viewBox、裁剪、transform、可见路径、fill-rule、描边和遮罩。`Document.paths()` 可能把分组路径和背景重新排序，不能靠其列表顺序直接判断真实绘制顺序。先看真实渲染，再提取明确路径；避免把 defs 中的裁剪框、版权符号、画布底色一并当 logo。带描边的开放路径需做精确描边转轮廓，不能直接按闭合填充拉伸。多路径归一化要共享总包围盒/坐标框，不能每条路径分别居中。

原始文件留档；梯度、透明度、阴影离散为纯色时写明映射。精简颜色不应改变字符、眼睛、镂空和笔画形状。用户要求暂停缺失素材时立即停止相应款式的推测制作。

## 原生建模

- Fusion 内部长度为 cm：mm 坐标除以 10。
- 闭合三次贝塞尔可用 `NurbsCurve3D.createNonRational(points, 3, [0,0,0,0,1,1,1,1], False)`，再 `sketchFixedSplines.addByNurbsCurve`。二次曲线可精确升阶；圆弧按可接受误差分解三次曲线，原始 SVG 保留。
- 原生曲线闭合失败时先检查退化线段、相切、重合控制点和填充规则。固定折线 fallback 不应悄悄代替用户要求的平滑曲线。
- 偶发零端点手柄可做有界微调，记录调整量；不能统一把极短曲线的手柄拉长到大于线段自身，造成回环。脚手架历史兼容量约 0.001 mm，必须按实际段长判断。
- 一个填充区域可包含洞和岛。通过轮廓包含关系选择正确 profile，核对 profile 面积；非零填充规则和自交轮廓需另外分析，不能总当 even-odd。
- 叠放 SVG 的实体按 painter order 扣除重叠，必要时先合并同色重叠体。所有正实体体积之和应等于轮廓面积 × 4 mm；每个嵌件 Z3..4。对裁切到板边的图案，裁切后重新确认身体/面外观。
- **Fusion CombineFeature.bodies 可能包含保留的工具体**。不能把其全部涂成目标体颜色，否则眼睛、嘴、其他分色会被染掉。只恢复目标体的外观，保留工具体颜色，并断言最后颜色集合与设计一致。
- 布尔运算后的目标可能产生多个实体；检查全部结果的颜色、体积和有效性，不假设永远只有第一个 body。
- ASCII 传输的 Fusion 脚本使用 `run(context)`，数据 JSON 用 UTF-8 显式读取。脚本中的中文路径可由初始化器写成转义字符串，避免本地 MCP 传输乱码。

## 几何与网格验证

核对精确轮廓的 40×40 范围、60% 平滑参数、总厚度 4、嵌件高度相同、底板无未授权孔位。检查全部原生特征 healthState、实体 isSolid、体积、颜色和 SVG 视觉一致性。STL 验证 watertight、winding、正体积及精度范围；三角面近似的包围盒应使用与网格公差一致的容差，不能用比导出公差更严的断言误报曲线。

实际遇过两类网格问题：
- SVG 零宽接触点导致 4 面共边：优先修正 CAD 拓扑；确需微小连接时量化偏差、记录位置，不以粗重描边覆盖整个标志。
- 原生封闭实体导出出现极小平面三角缺口：可对已定位的小缺口补三角面，但记录补面面积、面数、顶点/包围盒和体积差，并重新验证。不要用任意 remesh/平滑掩盖实质造型错误。

缩略图或集合预览应来自最终 mesh/BRep，检查镂空和分色；不要生成一张与真实模型不符的 AI 效果图当验证。默认不把内部 F3D、STL、预览图额外交付。
